# 高光谱目标跟踪科研绘图平台

基于 Python 和 PySide6 的本地离线桌面应用，用于高光谱目标跟踪指标计算、论文曲线绘制、跟踪结果可视化和属性评估。

当前版本：V1.4.0。软件包含指标评估、曲线绘制、跟踪可视化和属性评估四个业务页面，并新增 CSV Ground Truth/跟踪结果导入以及 HOTC2020、HOTC2023、HOTC2024 内置 Ground Truth。

Windows 用户可从 [Releases](https://github.com/sleeep913/HSITrackingPlotStudio/releases/latest) 下载免安装目录版，解压后运行 `HSITrackingPlotStudio.exe`。

## 已实现功能

- 新建、打开、保存、另存项目，维护最近 8 个项目。
- 未保存更改标记与关闭保护。
- 项目概览面板按项目信息、保存状态、数据源和跟踪器统计分区展示；长项目路径单行省略并保留完整悬浮提示。应用固定提供指标评估、曲线绘制、跟踪可视化和属性评估四个页签。
- Ground Truth、跟踪结果、图像序列、属性字典和默认导出目录的可视化配置。
- 跟踪器导入：扫描 `结果根目录/跟踪器/序列.txt`、`/跟踪器/模态/序列.txt`、`/跟踪器/带模态前缀的序列.txt` 三种布局；兼容 HOT2023 在跟踪器目录下使用 `all/ALL` 保存带模态前缀汇总结果的形式，候选布局支持打分、歧义判定与人工确认。
- HOT2023 Ground Truth 兼容：当所选目录同时包含 `ALL` 汇总目录与 `VIS/NIR/RedNIR` 镜像目录时，自动以带模态前缀的 `ALL` 为唯一数据源，避免把同一序列误报为重复键；仍可直接选择 `ALL` 目录。
- 序列映射：精确键匹配、无模态结果按名称回退匹配、跨模态同名歧义、缺失/额外序列、模态冲突与模态不匹配报告。
- 完整预检：源路径、Ground Truth 重复键、逐序列帧数不一致、部分 NaN/Inf、完整 NaN 缺失帧；有限数值的非正尺寸（包括 `[-1,-1,-1,-1]` 离屏标记）按旧 MATLAB 口径保留；报告可按级别、跟踪器、模态和关键字筛选，并导出 UTF-8 CSV 或 JSON。
- 可取消的后台任务机制：进度、成功、失败、取消信号，失败隔离，任务运行中的界面交互与关闭保护。
- 指标评估模块：选择跟踪器后固定计算 VIS、RedNIR、NIR 全部可用模态；跟踪器长列表位于左侧、选择与计算按钮集中在右侧；支持计算前摘要与阻塞检查、后台进度、取消后保留已完成结果和序列级失败隔离。
- 结果视图：固定 9 列 `Method × VIS/RedNIR/NIR/Average × AUC/DP@20` 横向主表，以及逐序列、失败与异常帧两个辅助页；界面默认显示四位小数，不可计算项显示 `—`。
- 结果导出：MAT（保留 `PASCAL_rec`、`distance_rec`、`average_cle_rec` 等旧版绘图字段）、CSV（UTF-8 BOM 长表，未四舍五入）、JSON（含完整曲线与全精度数值）；MAT 默认命名 `显示名称-AUC-DP.mat`，重名时先确认再覆盖或自动编号。
- CSV 可选择“完整结果”或“仅指标主表”；主表模式导出与界面一致的 9 列横向指标，并保留内部全精度数值。
- 曲线绘制模块：直接使用当前指标评估结果，也可一次导入多个平台或旧 MATLAB MAT；页面同时预览 Precision/DP 与 Success/AUC。
- 跟踪器曲线管理：显示/隐藏、重命名、移除、拖拽顺序；颜色列使用居中的小矩形预览，颜色选择器提供 28 个高区分度标准色、可增删并跨启动保存的“我的常用颜色”以及 `#RRGGBB` 输入，线型列使用带线段预览的内置下拉框。表格增加名次列，可按 AUC 或 DP 排名；Precision/DP 与 Success/AUC 图例继续独立支持升序、降序或当前顺序，互不覆盖。
- 曲线更新采用显式提交：勾选显示、修改名称/颜色/线型或改变图例排序后仅标记待刷新，不立即重绘；“全选”按钮可在全部勾选和全部取消之间切换，点击“刷新预览”后统一应用，避免连续操作时反复渲染。
- MATLAB 兼容绘图样式：Times New Roman、白底黑框、灰色虚线网格、固定坐标范围及 `名称[指标]` 三位小数图例；基础字号和线宽与旧版一致，跟踪器较多时在单列图例内按密度自动缩放字号、行距、示例线和曲线线宽。点击任一图例后可拖动右下角手柄同步缩放两张图的图例，双击恢复默认大小，范围为 60%–180%。
- 自包含绘图配方：`.hsirecipe.json` 版本 2 保存全部曲线、AUC/DP、分模态指标、名称、显示状态、颜色、线型、表格排名方式、图例缩放和两张图的排序；移走原 MAT 后仍可一次导入完整恢复，并兼容读取版本 1。
- 图形导出：一次选择目录和 PNG/PDF/SVG/EPS 格式，分别写出 `Precision_plots_OPE` 与 `Success_plots_OPE` 两个文件；画布随窗口尺寸和可见跟踪器数量动态增高，窗口停止缩放后自动重排，单列图例在密集场景中保持完整并远离主要曲线；矢量格式按相同规则调整画板尺寸。成对重名时使用同一自动编号，源码与打包版冒烟都会实际生成四种格式以验证导出后端。
- 跟踪可视化模块：一个页面内选择模态、序列、主方法和对比方法；固定尺寸画布叠加 Ground Truth 与多跟踪器边界框，提供帧输入、滑块、上一帧、播放/暂停/停止、下一帧、速度、范围和循环控制，并支持滚轮缩放、拖动平移、适应窗口与原始尺寸视图。
- 可视化样式与缺失状态：跟踪器边界框直接复用项目 `tracker_id` 对应的颜色、线型和线宽，Ground Truth 固定为蓝色；完整 `[-1,-1,-1,-1]`、完整 NaN、结果越界或缺图均显示明确状态且不会残留上一帧矩形。
- 优势帧筛选：指定一个主方法和用户勾选的对比方法后，复用 MATLAB 兼容逐帧 IoU，以主方法 IoU 不低于 0.5、严格领先全部对手和时间去重为条件，确定性推荐最多 5 帧；点击候选帧号只切换预览，由用户确认后再加入 Visual 清单。
- 跨序列 Visual：右侧清单可累计多个序列，每个序列固定选择 3 帧；最终按一序列一行生成 `X×4` 论文拼图，第一列为只绘 Ground Truth 的第 1 帧，后三列按所选帧号升序排列。底部图例固定为单行并按实际宽度动态缩小，可导出 PNG/PDF/SVG/EPS。
- 可视化导出与配方：当前帧和区间支持 PNG/PDF/SVG/EPS，MP4 支持范围、帧率、分辨率、图例、后台进度、取消清理和完成后重新校验；`.hsirecipe.json` 保存序列、跟踪器 ID、显示/播放/视频参数、候选帧和 Visual 清单，但不嵌入图像、TXT 或视频。
- 属性评估模块：分别导入属性字典、Ground Truth 和跟踪器结果根目录；属性表显示属性名称、序列数和完整序列清单，计算任务复用既有全模态 MATLAB 兼容指标管线，空属性结果显示 `—` 而不写为 0。
- 属性结果与导出：页面采用“属性与序列 / 计算结果”两个全宽页签；结果表按“跟踪器为行、属性为列”转置展示，并通过 AUC/DP@20 按钮切换。“绘图跟踪器”复选菜单可逐个选择、全选或清空，仅影响雷达图，不影响结果表；所选方法随项目保存。一次导出生成 `<项目名>_attributes.pdf`，在同一页左右并列绘制所选方法的 AUC 与 DP 雷达图并共用底部图例，颜色与线型复用项目稳定样式，重名自动编号。
- 项目计算缓存：指标评估、曲线数据、属性评估、跟踪可视化索引、优势帧及 Visual 清单随 `.hsiproj` 保存；大型索引写入项目旁的 `<项目名>.hsicache`，另存为时自动复制。缓存按源文件元数据、参数和算法版本指纹校验，变化后自动失效；“文件 → 清除项目缓存”可仅删除派生结果而保留数据源与跟踪器配置。
- 统一的浅色科研工具主题、卡片、按钮、表格和状态色规范。
- 跟踪器稳定样式：颜色、线型和线宽按跟踪器标识绑定，重排或重新导入后保持不变。
- CLE、Precision/DP、IoU、Success/AUC 及逐序列/分模态/总体等权聚合算法；完整 NaN 预测帧排除，完整 `-1` 行按 MATLAB 公式正常参与计算。
- Windows 目录版可执行程序打包。

## 开发环境

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m hsi_plotter
```

执行静态检查：

```powershell
.\.venv\Scripts\python.exe -m ruff check src tests
```

直接运行打包版：

```powershell
.\HSITrackingPlotStudio-v1.4.0\HSITrackingPlotStudio.exe
```

V1.4.0 已完成完整自动化质量门禁。指标实现曾使用真实 HOT2023/LRSST 的 87 个序列复核，得到 `AUC=0.6398`、`DP=0.8672`，与旧 MATLAB 结果一致。真实 HOT2023 属性字典可读取 12 个属性，同格式 Ground Truth 可识别 87 个序列，结果目录扫描无结构错误。真实 HOTC2026 FalseColor 根目录可自动识别 75 个序列和 30,338 帧（VIS 40、RedNIR 13、NIR 22），无扫描错误；图像与跟踪结果扫描在后台执行。

重新打包：

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath .\dist-v1.4.0 --workpath .\build\v1.4.0 .\packaging\hsi_tracking_plotter.spec
```
